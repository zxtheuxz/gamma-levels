# Continuidade do projeto

Antes de analisar, modificar ou responder sobre este projeto, leia integralmente
`PROJECT_MEMORY.md`. Ele contém as decisões do usuário, metodologia, resultados
já concluídos, bancos preservados e instruções para retomar os processos.

Estados de processos em andamento são temporais: consulte a API local antes de
informar progresso. Não execute novamente um estudo completo já concluído sem
pedido explícito. Depois de cada resultado ou alteração material, atualize
`PROJECT_MEMORY.md` para manter a continuidade entre sessões.
